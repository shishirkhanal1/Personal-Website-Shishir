## 🎨 Design System

- **Shared Layout**: [`src/layouts/Layout.astro`](file:///c:/Users/iqora%20medax/Desktop/Personal%20Website/src/layouts/Layout.astro)
- **Responsive Navbar**: [`src/components/Navbar.astro`](file:///c:/Users/iqora%20medax/Desktop/Personal%20Website/src/components/Navbar.astro) (Active page indicators, glassmorphic backdrop, mobile drawer)
- **Responsive Footer**: [`src/components/Footer.astro`](file:///c:/Users/iqora%20medax/Desktop/Personal%20Website/src/components/Footer.astro) (Quick links, contact coordinates, availability status)
- **Color Palette**: Deep cosmic obsidian (`#06080d`), elevated slate (`#0d111a`), neon cyan accents (`#00f0ff`), growth emerald (`#10b981`), and subtle electric indigo (`#6366f1`).
- **Typography**: Space Grotesk / Syne for high-impact headings, Plus Jakarta Sans for body copy, and JetBrains Mono for telemetry metrics.
